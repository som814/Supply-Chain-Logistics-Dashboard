# 📦 Supply Chain & Logistics Dashboard

## 📌 Project Overview
This project is an interactive Supply Chain & Logistics Dashboard built using Power BI. It provides insights into supplier performance, inventory management, shipment tracking, customer analysis, and business KPIs to support data-driven decision-making.

## 🚀 Features
- Executive KPI Dashboard
- Supplier Performance Analysis
- Inventory Analysis
- Shipment Analysis
- Customer Analysis
- Interactive Filters & Slicers
- Business Insights

## 🛠️ Tools & Technologies
- Power BI
- PostgreSQL
- SQL
- Power Query
- DAX
- Excel

## 📊 Key KPIs
- Total Revenue
- Profit
- Profit Margin
- Order Quantity
- Inventory Value
- Shipment Quantity
- Perfect Order %
